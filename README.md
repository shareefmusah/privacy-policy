# Gist Privacy Policy

This repository hosts the official Privacy Policy for the **Gist** mobile app, accessible to Google Play Console and all university users.

## Live URL
When GitHub Pages is enabled on the `main` branch, this page is published live at:
👉 **https://shareefmusah.github.io/privacy-policy/**

## Enabling GitHub Pages
1. Go to this repository on GitHub: https://github.com/shareefmusah/privacy-policy
2. Click **Settings** (top tabs) &rarr; **Pages** (left sidebar).
3. Under **Branch**, select `main` and root (`/`), then click **Save**.
4. In about 1 minute, the live site will be active and ready to paste into Google Play Console!
